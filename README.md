呱呱是一款 Windows 桌面信息岛：平时收在屏幕顶部，鼠标靠近时展开。它使用 Rust 和 egui 构建，无需 Electron。

## 桌面伙伴

在「设置 → 桌宠」中可以开启独立的麻薯桌宠，调整大小和主题颜色。它的眼睛会跟随鼠标；拖动它可调整位置，点击它会得到表情反馈。桌宠遵循“全屏时隐藏”设置。

麻薯桌宠拥有与信息岛吉祥物对应的表情，并会根据音乐、天气、专注和空闲等状态独立互动；在桌宠设置页可以逐项预览表情和动作。

身体动作包括待机呼吸、点击弹跳、拖拽变形、伸懒腰、靠近回应、听歌摇摆与打盹醒来，可在桌宠设置页关闭或预览。

呱呱有 12 组表情动画：**眨眼、得意、脸红、开心、侧目、被夸、比心、偷笑、害羞探头、巡视、探头、左右张望**。

它还会根据状态呈现待机、好奇、唤醒、专注、担忧、打盹、睡眠、听歌、眩晕和拖动动作。

- **日常互动**：待机、鼠标经过、完成事项和喝水时会有对应反馈，听歌时也会在演唱动作之间穿插表情。
- **天气表情**：取得天气或天气变化时，呱呱会在合适的待机时机展示对应动作；天气保持不变时，也会偶尔再次展示。
- **接着听歌**：面板展开、音乐暂停或通知打断后，恢复时继续之前的听歌动作；完成事项和喝水的反馈会优先展示。吉祥物暂时隐藏时，相关动画和反馈会暂停计时。
- **摇晃鼠标**：在桌面上持续快速左右摇晃鼠标约 5 秒，呱呱会短暂露出眩晕表情。
- **拖动小岛**：呱呱会偶尔拖动岛体，稍后回到原位。可在「设置 → 常规 → 吉祥物随机拖动」关闭或调整速度、距离和间隔；操作小岛或出现提醒时会让位。

## 功能介绍

| 功能 | 能做什么 |
| --- | --- |
| **音乐与歌词** | 显示歌曲、歌手和封面，控制播放、暂停、切歌及进度；展开时显示歌词，也可在收起的小岛上显示当前一句。支持调整歌词时间。 |
| **专注与饮水** | 使用专注／休息计时；设置每日饮水目标、单次饮水量、提醒间隔与时段，记录后可撤销。 |
| **待办** | 添加、编辑、完成待办，并为事项设置可选的到期提醒。 |
| **文件置物架** | 将文件拖到岛上临时收集，可打开、定位或拖出文件；移除记录不会删除原文件。 |
| **日程** | 查看月历，创建、编辑和删除本机日程；合并显示工作日历和邮件中的正式日历邀请，并按设置提前提醒。 |
| **邮箱** | 连接多个邮箱，查看收件箱摘要和正文；识别邮件验证码并点击复制。 |
| **AI 额度** | 查看 Codex、Claude、Kimi、Grok Bot 和 Gemini 的额度信息；支持账号备注、颜色和常驻显示。 |
| **系统与通知** | 显示电量、充电、网络、音量、键盘状态和蓝牙设备等提示；可连接 Windows 通知并按应用开关。 |
| **天气** | 岛上显示天气图标与当前温度；默认广东深圳，也可自动定位或手动选择城市。 |

音乐主要通过 Windows 媒体会话获取，并针对网易云音乐、QQ 音乐、酷狗音乐和汽水音乐做了兼容处理。播放器需要提供可用的媒体信息；歌词显示取决于歌曲信息、来源和网络。

呱呱支持极简刘海、浏览器贴顶时自动极简、全屏隐藏，以及功能页面和常驻组件的显示与排序。设置窗口可选择跟随系统、浅色或深色主题。

「设置 → 常规 → 岛体外观」提供经典黑、奶油、毛玻璃·浅、毛玻璃·深和悬浮云五款皮肤，可自由搭配刘海或胶囊形态。毛玻璃可开启 Windows 背景模糊；悬浮云随音乐封面换色，并显示鼠标光晕和进度光效

## 开始使用

### 获取程序

可在 [Releases](https://github.com/tuoziqiao/pet-gua/releases) 查看是否有安装包或免安装压缩包。如果当前没有发布文件，请按下面的步骤从源码构建。

### 从源码构建

需要：

- Windows 10／11 x64，以及支持 OpenGL 的显卡驱动。
- Rust stable 的 Windows MSVC 工具链、Visual Studio C++ 构建工具和 Windows SDK。
- 首次构建时连接 crates.io 和 GitHub，以获取 Cargo 依赖。

```powershell
git clone https://github.com/tuoziqiao/pet-gua.git
cd pet-gua
# 调试构建并直接运行
cargo run --bin gua
# 发布构建
cargo build --locked --release --bin gua
.\target\release\gua.exe
```

Cargo 的内部程序目标名仍为 `gua`，因此直接构建得到 `gua.exe`；程序界面显示名称由 `branding.json` 决定。

### 初次使用

1. 启动程序后，将鼠标移到屏幕顶部的小岛，展开功能面板。
2. 使用面板左右箭头或底部圆点切换页面；点击齿轮或托盘菜单中的「设置」调整功能。
3. 按需连接邮箱、工作日历或 AI 账号。应用通知需要在设置中连接 Windows 通知并授予系统权限。

## 打包

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

脚本默认在 `dist` 目录生成安装程序、免安装 ZIP 和 `SHA256SUMS.txt`。文件名从 `branding.json` 读取 `package_name` 和 `version`，形如 `package_name-Setup-v版本号-x64.exe` 和 `package_name-v版本号-windows-x64.zip`；ZIP 内的程序名同样来自 `package_name`。已有同名结果时，新结果会放入单独的构建目录。

打包需要 NSIS 3；如果本机未安装，脚本会尝试下载并校验 NSIS 3.13，也可以通过 `-NsisCompiler` 指定已有的 `makensis.exe`。仓库通过 `vendor/imap` 引用本地补丁；`eframe` 从 crates.io 获取，`vendor/eframe` 为保留的旧版源码，不参与构建。构建需要 Rust 1.95 或更高；不提交 `target/` 或打包产物。

## 连接服务

- **邮箱**：支持 QQ、163、126、腾讯企业邮、iCloud 和 Gmail。通常需要开启 IMAP 并使用授权码或应用专用密码。
- **工作日历**：支持飞书、钉钉和企业微信，远程日历以只读方式同步；本机日程保存在本地。连接时需要相应平台提供的日历账号和凭据。
- **AI 额度**：可识别部分本机已登录账号，Grok Bot 和 Gemini 也提供各自的连接方式。可用的额度字段取决于服务、订阅和登录状态。

第三方接口和账号策略可能变化；连接或查询失败时，请结合程序提示检查授权和网络。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 数据与权限

- 设置、待办、饮水记录、本机日程和连接元数据默认保存在 `%APPDATA%\gua`。可通过环境变量 `GUA_DATA_DIR` 指定其他数据目录。
- 天气启用时使用 Open-Meteo 获取所选位置的天气；自动定位通过公网 IP 推测位置，可在设置中关闭天气或改选城市。城市及最近天气缓存在本机。
- 邮箱和日历密码使用 Windows 凭据管理器保存；独立 Gemini 会话使用当前 Windows 用户的 DPAPI 加密。
- 置物架记录文件路径，不复制文件正文。启用邮箱、日历、AI 额度或歌词等功能时，程序会访问对应的第三方服务。
