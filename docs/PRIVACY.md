# 隐私与安全

## 本机数据

呱默认在 `%APPDATA%\gua` 保存用户设置、待办、本机日程、节日提醒、饮水记录、置物文件路径、连接元数据以及忽略的邮件日程标识。环境变量 `GUA_DATA_DIR` 可指定另一目录。置物架保存原文件路径，不复制文件正文。本机日程和节日提醒不上传到工作日历；农历和节气使用本机计算。

邮箱和日历密码通过 Windows 凭据管理器保存；独立 Gemini 会话使用当前 Windows 用户的 DPAPI 加密后保存在数据目录。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。当前邮件记录保存在内存中；不要将运行中的内存转储公开分享。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

当前设置中不提供应用内更新入口；如需更新，可通过浏览器访问 GitHub 发布页，手动下载新版安装包。

程序不使用统一的呱云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由呱自己的安全存储管理。不要把 Cookie、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。

## 反馈安全问题

请使用仓库的私密漏洞报告入口，见 [SECURITY.md](../SECURITY.md)。普通 UI 问题可以开公开 Issue，但请先去除敏感信息。

切换到和风天气后，城市搜索、实况和七日预报请求发送到用户填写的 `qweatherapi.com` 专属域名。默认 Key 内置于程序及源码，获取程序的人可以提取并使用该 Key；保存的自定义 Key 存放在 Windows 凭据管理器中，请求通过 HTTPS 请求头发送，不写入普通设置或天气缓存。来源、城市、预报缓存及本机每月请求次数保存在呱的数据目录；搜索、连接测试和刷新等出站请求计入 5,000 次本机月限额。关闭天气后不再发起新请求并丢弃在途结果。

启用 Open-Meteo 天气时，自动定位会先访问 ipwho.is，必要时尝试 free.freeipapi.com；城市搜索可能访问 Open-Meteo 地理编码服务，天气请求发送所选坐标。请求优先直连，必要时使用系统或环境变量配置的代理。

查看生活指数时，无论当前天气来源为何，程序会将当前城市经纬度发送给已配置的和风 API Host，并使用默认或已保存的和风 Key；请求计入上述本机月限额。指数结果、城市坐标、日期和数据归因缓存在呱的数据目录，不包含 Key。关闭天气或切换城市、天气来源及凭据后，不再采用旧请求的结果。

查看小时天气预报时，无论当前天气来源为何，程序都会将当前城市经纬度发送至和风 API Host，请求计入同一本机月限额。小时预报、城市坐标及数据来源缓存在呱的数据目录中，不包含 Key；离开详情或切换城市、来源、凭据时不再采用旧请求的结果。

天气预警和分钟降水暂时关闭，不会为这两项功能向和风发送请求。
