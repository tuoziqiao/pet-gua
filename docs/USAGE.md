# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

吉祥物开启时，在桌面任意位置持续快速左右摇晃鼠标约 5 秒，呱会短暂露出眩晕表情。停止摇晃约一秒后，可以再次触发。

呱也会偶尔伸手拖动小岛，停一会儿后再回到原位；操作小岛或出现提醒时会先停下。可在「设置 → 常规 → 吉祥物随机拖动」关闭特效，或调整移动速度（50%～200%）、距离（80～400 逻辑像素）和平均间隔（2～60 分钟）。默认平均间隔为 10 分钟，实际等待约 5～15 分钟；修改间隔时，等待中的下一次拖动会重新计时。实际距离会在设置值的 75%～125% 之间随机，并受屏幕边缘限制；速度和距离的新设置从下次拖动开始生效。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

在「设置 → 天气」开启或关闭天气，并搜索城市、区县以手动选择；未配置城市时默认使用广东深圳，也可以切换为网络自动定位。自动定位根据公网 IP 推测，使用代理时可能不准确。天气每小时刷新，暂时失败时保留最近 3 小时内的结果；可在「设置 → 页面管理 → 常驻排列」中拖动天气组件。

吉祥物会在取得天气、天气或昼夜状态变化时，以及待机累计约 5 分钟后，展示对应的天气动作。动作会为提醒、互动和其他吉祥物状态让位；关闭天气或 Windows 动画效果后不会自动播放。

在「设置 → 常规 → 岛体外观」选择经典黑、奶油、毛玻璃·浅、毛玻璃·深或悬浮云，并独立选择刘海或胶囊形态。毛玻璃可开关背景模糊；Windows 透明效果关闭或模糊不可用时使用半透明底色。悬浮云随音乐封面和鼠标位置变化，缺少封面时使用中性色。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址。选择 Outlook 时使用微软浏览器授权；其他服务商填写授权码或 App 专用密码。不要把密码或令牌发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |
| Outlook / Microsoft 365 | 个人 Outlook.com、Hotmail、Live 邮箱先在 Outlook 网页版「设置 → 邮件 → 转发和 IMAP」开启 IMAP，再填写邮箱并选择「浏览器登录并添加」。工作或学校账号可能需要管理员允许 IMAP 和应用授权 |

以服务商当前页面为准，呱设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；呱不会替你改变系统网络设置。

Outlook 授权页面由微软提供，账号密码不输入呱。微软的 IMAP 授权包含读取和修改邮箱的权限，呱以只读方式打开收件箱并读取邮件。登录失效时可在邮箱列表选择「重新授权」；删除邮箱会删除本机加密的 Outlook 凭据。工作或学校账号如果提示需要管理员批准，应联系所在组织的管理员。

Outlook 功能依赖项目维护者注册微软应用并在构建时配置客户端 ID。如果设置页提示此版本未配置客户端 ID，需要维护者完成 [接入配置](OUTLOOK-SETUP.md) 后重新构建；没有配置时不能连接真实 Outlook 邮箱。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文内的网页链接交给默认浏览器打开。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予呱日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、饮水与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## AI 额度

先登录相应工具，再在呱 AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的本机登录由原工具管理，呱不会修改它们的配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

## 更新、卸载与数据目录

本项目可在构建前通过 `branding.json` 自定义界面显示名和英文打包名。本指南中的呱和 `gua` 是默认名称；修改品牌后，请使用新名称对应的安装包和程序。英文打包名变更时，原版本需先运行新安装包完成升级；用户数据和已连接账号仍沿用原位置。

双击新版 `gua-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。新安装位置默认为 `%LOCALAPPDATA%\Programs\gua`；升级沿用原安装位置，也可选择其他有写入权限的文件夹。用户数据仍保存在 `%APPDATA%\gua`。

可从发布页下载新版进行升级，呱的后续升级会保留呱的数据。若提示呱正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在呱设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查呱是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。
